Équivalences SolidWorks

  • Esquisse : circle, rectangle, roundedRectangle, polygon({points}), star, ellipse
  • Bossage extrudé : extrudeLinear({height}, esquisse)
  • Révolution : extrudeRotate({segments:64}, profil) (profil avec x ≥ 0)
  • Enlèvement de matière, perçage : subtract(a, b)
  • Fusion : union(a,b) · Intersection : intersect(a,b)
  • Congé simple : roundedCuboid, roundedCylinder (roundRadius)
  • Chanfrein de toutes les arêtes d’une boîte : cuboidChamfer(l,p,h,c)
  • Texte 3D : texte3d('SUGAR',{height:12,epaisseur:2,profondeur:4})
  • Congé 2D et chanfrein 2D avant extrusion : fillet2d(esquisse, r), chanfrein2d(esquisse, c)
  • Réseau polaire : reseauPolaire(piece, n, 360) · linéaire : reseauLineaire(piece, n, [dx,dy,dz])
  • Déplacer à la souris : bouton Déplacer, clique une pièce puis tire une flèche
  • Aperçu de tranchage : bouton Tranches
  • Combiner des programmes : onglet Exemples, choisis l’action puis clique un exemple
  • Coque : soustraire une forme plus petite
  • Réseau : une boucle for ou Array.from
  • Symétrie : mirror({normal:[1,0,0]}, s)
  • Déplacer, tourner : translate([x,y,z],s), rotateX(deg(90),s), rotateY, rotateZ
  • Enveloppe : hull(a,b) · Couleur : colorize([r,g,b],s) (0 à 1)
  • Formes 3D : cuboid, cylinder, sphere, torus, cylinderElliptic

Pas de congé ni de chanfrein sur arête choisie, pas de mise en plan. Export STL pour l’impression 3D ou l’ouverture dans SolidWorks (importer un fichier STL).

Python (CadQuery) : un vrai noyau CAO (OpenCascade) avec congés et chanfreins sur arêtes choisies, vues 2D, assemblages avec contraintes et export STEP pour SolidWorks. Nouvelles fonctions de forme

loft(a, b, {h:50, pas:12, twist:45}) transition entre deux esquisses 2D (cercle → carré…).


balayage(profil2D, chemin) profil le long d’un chemin 3D [[x,y,z],…]. Pour un tube : soustraire deux balayages. Aides : helice(r, pas, tours), arc3d(r, angle).


miroir(forme, 'x') symétrie fusionnée avec l’original ; miroir(forme,'x',false) seulement la copie.
